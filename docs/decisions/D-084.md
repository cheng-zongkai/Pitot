# D-084 Intel CPU sensors through the PawnIO IntelMSR module

Accepted · 2026-11-11
Decision: on Intel CPUs (CPUID `GenuineIntel`), `IntelSensors` reads package temperature, package power, and effective frequency through the signed PawnIO `IntelMSR` module (PawnIO.Modules 0.2.11, embedded in `Pitot.exe`), sharing the RAPL energy and APERF/MPERF logic with AMD Zen in `src/sensors/cpu_meters.h`. See [Intel CPU metrics](../subsystems/cpu.md#intel) for registers and formulas.
Implementation points:
- Snapshot temperature is `cpu_temp` paired with `cpu_vendor`, producing distinct sensor keys (`amd.tctl` vs `intel.package`).
- Feature presence is determined by CPUID bits (CPUID 6 EAX [6]) and non-zero MSR reads (`TjMax`, `RAPL_POWER_UNIT`, `PLATFORM_INFO`); unsupported metrics are hidden rather than guessed (for example, Pitot does not assume TjMax = 100 °C if MSR `0x1A2` reads 0).
- MSR reads require no shared mutex (no SMN access).
Status: implemented and unit-tested (`tests/sensors_decode_test.cpp`); not yet hardware-verified on an Intel machine.
Rejected: per-core MSR temperature polling (adds per-core affinity hops every 2 s even while idle) and hard-coded microarchitecture tables.
