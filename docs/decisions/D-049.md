# D-049 Flyout Acrylic via WS_POPUP | WS_CAPTION and collapsed non-client area

Accepted · 2026-11-05 · Refines D-024
Problem: on a plain `WS_POPUP` window, `DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_TRANSIENTWINDOW` succeeds yet DWM renders a solid fallback color because DWM only composes system backdrops on windows with a frame.
Decision:
1. Use `WS_POPUP | WS_CAPTION` with `DWMWCP_ROUND`.
2. Return `0` from `WM_NCCALCSIZE` when `wParam == TRUE` to collapse the caption/frame to 0 px.
3. Call `SetWindowPos(..., SWP_FRAMECHANGED)` before showing so the first frame uses the collapsed layout.
4. Return `HTCLIENT` from `WM_NCHITTEST` so title-bar buttons remain clickable and dragging is disabled.
Note: Windows replaces Acrylic with a solid color whenever the window is inactive (visible only when pinned and unfocused).
Rejected: `WS_EX_LAYERED` + `UpdateLayeredWindow` (solid fallback only), undocumented `SetWindowCompositionAttribute`, and DirectComposition (requires D3D/DComp, conflicting with D-024's memory trade-off).
