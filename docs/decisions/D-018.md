# D-018 Taskbar strip uses Direct2D software rendering

Accepted · 2026-11-04
Decision: render the strip onto a 32-bit premultiplied DIB using software `ID2D1DCRenderTarget` (`D2D1_RENDER_TARGET_TYPE_SOFTWARE`) and present via `UpdateLayeredWindow`. Do not create a D3D device.
Reason: at taskbar sizes (e.g. 480 × 96 px at 200% DPI), CPU rasterization is negligible while avoiding several MB of resident D3D device/swap-chain memory.
