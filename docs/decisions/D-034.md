# D-034 Project license: MIT

Accepted · 2026-11-04 · User decision
Decision: Pitot's own source code uses the MIT license, `LICENSE` in the root, copyright holder kyzon (the git user name).
Reason: the agent recommended a permissive license. The GPL cannot be distributed together with AMD's proprietary `PitotAdlx.dll`; MIT also does not conflict with the embedded LGPL PawnIO modules (which allow modification and reverse engineering).
- `LICENSE` contains only the MIT text, so that GitHub can recognize the license type. Notes such as "the PawnIO modules are LGPL and `PitotAdlx.dll` is distributed under the AMD agreement" are written at the start of `THIRD_PARTY_NOTICES.md`.
- `src/adlx/pitot_adlx.cpp` is itself code written by Pitot and is also MIT; the DLL built with the ADLX headers is distributed under the AMD agreement (D-033).
