# D-063 ETW shared buffer and QPC round splitting

Accepted · 2026-11-06 · Refines D-007
Decision:
- Open the ETW session with `EVENT_TRACE_NO_PER_PROCESSOR_BUFFERING` (shared buffer) and consume with `PROCESS_TRACE_MODE_RAW_TIMESTAMP` (QPC timestamps, `ClientContext = 1`).
- On each sampling round, capture a QPC boundary (`KernelTrace::Cut`), read adapter and disk PDH counters immediately, then flush the ETW session. Events after the boundary are bucketed into the next round (`IoBuckets`), and rates use exact QPC elapsed time.
Reason: with per-processor buffers, `EVENT_TRACE_CONTROL_FLUSH` under low load failed to flush some CPU buffers for ~1 s, shifting the process list one round behind the device cards. Measured with 64k/s 4 KB random reads: 0 lost events and lower CPU than per-processor buffering (0.083% vs 0.161%).
Rejected: undocumented millisecond `FlushTimer` flags.
