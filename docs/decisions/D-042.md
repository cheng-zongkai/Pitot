# D-042 Separate-process Settings window with native Mica

Accepted · 2026-11-04 · Updated 2026-11-05
Decision:
- **Process isolation**: `Pitot.exe --settings` runs as a separate process with its own single-instance mutex `Local\Pitot.Settings` and exits on close. The main process calls `ImmDisableIME(-1)` (D-024), whereas Settings needs IME/caret text input and hardware D2D (~45 MB private commit while open) without affecting the tray process's memory budget.
- **Live apply via INI + shared memory**: every change writes immediately to `%APPDATA%\Pitot\config.ini` (UTF-16LE with BOM via `WritePrivateProfileStringW`), and the main process reloads via directory change notification. The live sensor list for the Sensors page is read from shared memory `Local\Pitot.Sensors` published by the main process.
- **Window material**: uses native Windows 11 system Mica composed by DWM (`DWMWA_SYSTEMBACKDROP_TYPE`), keeping the system title bar and frame without laying a custom semi-transparent tint over the whole window.
