# D-007 ETW uses a private system logger

Accepted · 2026-11-04 · Source: `Pitot.md`, "Architecture and Threading Model" and "Risks and Open Questions"
Decision: open a session named `Pitot-Trace` with `EVENT_TRACE_SYSTEM_LOGGER_MODE`, enabling TCP/IP, disk I/O and thread events; stop it as soon as the panel closes; clean up a same-named leftover session at startup.
Rejected: using the single "NT Kernel Logger". Reason: tools such as WPR may be occupying it, and it would also take over someone else's session.
