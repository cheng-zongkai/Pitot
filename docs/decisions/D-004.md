# D-004 PawnIO is called directly through DeviceIoControl

Accepted · 2026-11-04
Decision: open `\\?\GLOBALROOT\Device\PawnIO` directly via `DeviceIoControl` without `PawnIOLib.dll`. The signed PawnIO modules (`AMDFamily17`, `IntelMSR`, `LpcIO`) are embedded as resources in `Pitot.exe`, each with its own handle.
Reason: avoids an extra runtime DLL dependency and keeps module loading self-contained.
Note: PawnIO modules are LGPL-2.1-or-later; releases must include the license text and source provenance (`THIRD_PARTY_NOTICES.md`, `third_party/pawnio/`).
