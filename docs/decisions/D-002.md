# D-002 Run as administrator, autostart through a scheduled task

Accepted · 2026-11-04
Decision: Pitot runs elevated; logon autostart uses the scheduled task `\Pitot\Autostart` with highest privileges (no UAC prompt). The task itself is the source of truth for autostart state.
Reason: PawnIO hardware access, kernel ETW sessions, and `SystemMemoryListInformation` all require administrator rights.
Cost: UIPI isolation with the non-elevated Explorer shell (addressed in D-013).
