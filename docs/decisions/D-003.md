# D-003 Coexisting with FanControl: shared mutexes, hardware is read-only

Accepted · 2026-11-04 · Source: `Pitot.md`, "Goals and Constraints" and "Risks and Open Questions"
Modified 2026-11-11: the read-only rule was dropped at the user's request and other Super I/O chips were added (D-085). The writes Pitot makes are listed in `hardware.md`, "Writes Pitot performs".
Decision: hold `Global\Access_PCI` for SMN access and `Global\Access_ISABUS.HTP.Method` for EC access, and skip the round if the mutex cannot be acquired within 10 ms. Never write any configuration register.
Reason: if two programs use the SMN index / data register pair or the EC page register at the same time, they interrupt each other and the readings jump. These two names are the common convention among LibreHardwareMonitor-family tools.
