# D-001 Tech stack: C++20 + Win32 + Direct2D/DirectWrite + DWM

Accepted · 2026-11-04
Decision: native Win32/C++20 with Direct2D/DirectWrite and DWM; no dependency on .NET, WinUI, Qt, or bundled JSON parsers. The only third-party pieces in the product are the signed PawnIO modules and the optional AMD ADLX SDK (`PitotAdlx.dll`).
Reason: with a ~10 MB best-effort private memory target and ≤ 0.5% idle CPU budget, a managed runtime or XAML framework alone would exceed the budget.
