# D-091 Windows installer built with Inno Setup

Accepted · 2026-11-16 · User decision
Decision: Each release ships an Inno Setup installer (`Pitot-<version>-setup.exe`, compiled from `installer/Pitot.iss`) and a portable zip with the same files, plus `SHA256SUMS.txt`; a loose `Pitot.exe` or DLL is never a release asset. CI builds both without `PitotAdlx.dll`, and `scripts/repack-adlx.ps1` rebuilds them on the maintainer's machine with the locally built DLL and its agreement inside (D-033).
Reason: The user asked for an exe installer instead of a stand-alone exe and loose DLLs. Inno Setup produces one setup exe, needs nothing installed on the user's machine, is free for any use under a permissive license, and its Pascal scripting covers closing Pitot cleanly and removing the autostart task. It is a build tool only; the setup program it embeds in the installer keeps its own copyright notice (`THIRD_PARTY_NOTICES.md`).
Details:
- Per-machine install into `Program Files\Pitot` with administrator rights, which Pitot needs anyway (D-002); x64 Windows 11 only.
- Pitot is closed with `WM_CLOSE` to `Pitot.Main` / `Pitot.Settings`, then the `Local\Pitot.*` mutexes are awaited. Restart Manager is off because it would end Pitot before it saves its traffic counters.
- Uninstall removes `\Pitot\Autostart` only when it runs the installed exe, and never deletes user data.
- Inno Setup 6.7.3 and its unofficial Simplified Chinese messages file are pinned by SHA-256 in `scripts/get-innosetup.ps1`, because the windows-2025 runner image does not include Inno Setup.
- Pitot.exe and PitotNvidia.dll inside the repacked files are the ones CI built from the tag; only the AMD DLL comes from the maintainer's machine.
Rejected:
- WiX / MSI: a heavier toolchain and more authoring for a one-folder app, and the user asked for an exe.
- NSIS: comparable output, but lower-level scripting for the close and task-removal logic.
- Building the whole release locally: CI keeps building and testing from the tag, so only the AMD DLL depends on the maintainer's machine.
